# 拾分 · 一起记分

## 运行

在本目录启动静态网页：

```bash
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000/>。

网站源码会通过 GitHub Pages 发布。部署完成后，直接访问仓库对应的 Pages 地址即可。

## 功能

- 新建或加入记分房间
- 分享房间码和邀请二维码
- 查看伙伴积分排行与积分明细
- 给伙伴记分、相互转分，或手动调整积分（允许负分）
- 在本机保存积分，并导出/恢复 JSON 备份

数据保存在当前浏览器本地，不同设备之间暂不共享房间或同步积分。清除浏览器网站数据可能会删除积分记录，建议定期导出备份并妥善保存；浏览器也可能支持为网站申请本地数据保护。二维码生成依赖联网加载 QRCode.js。
