# 拾分 · 一起记分

## 运行

在本目录启动静态网页：

```bash
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000/>。

网站源码会通过 GitHub Pages 发布。部署完成后，直接访问仓库对应的 Pages 地址即可。

## 功能

- 新建或加入记分房间
- 分享房间码和邀请二维码
- 查看伙伴积分排行与积分明细
- 给自己或伙伴记积分、相互转分

演示数据保存在当前浏览器本地。不同设备之间暂不共享房间或同步积分；正式多人使用还需要服务端、用户身份和数据库。二维码生成依赖联网加载 QRCode.js。
